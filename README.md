# Voting App

A multi-container application demonstrating Docker, docker-compose, and microservices architecture. 

## Architecture

- **Frontend**: NGINX serving HTML on port 8080
- **Backend**: Flask API on port 5000
- **Database**: Redis for data storage

## Prerequisites

- Docker
- docker-compose
